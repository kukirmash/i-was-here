# Техническая спецификация: Клиентский генератор «Среза агата» по Timestamp

Документ описывает архитектуру, математическую модель, систему генов, мутаций и послойный конвейер отрисовки процедурного среза агата на стороне клиента.

**Единственный входной параметр с сервера:** неизменяемое 64-битное целое число `created_at_ms` — момент создания учётной записи пользователя в формате Unix Timestamp (миллисекунды в UTC). Никакие изображения, цвета или настройки артефакта на сервере не хранятся.

---

## 1. Общая архитектура пайплайна

Вся генерация выполняется локально на устройстве пользователя и разделена на 5 детерминированных этапов:

1. **Нормализация входа и хэширование:** разложение 64-битного `created_at_ms` на UTC-компоненты времени и независимые 32-битные начальные значения (seed) с лавинным эффектом.
2. **Сборка генома:** вычисление макро-признаков (время суток, сезон, возраст аккаунта), микро-признаков (геометрия, палитра, слои) и независимая проверка редких мутаций.
3. **Построение геометрии:** расчёт внешнего контура камня, вложенных колец породы, полости жеоды, граней кристаллов и геометрии мутаций в нормализованных координатах `[-1, 1]`.
4. **Запекание статического буфера:** однократная отрисовка камня, фактуры и статичных мутаций в невидимый буфер высокого разрешения (с учётом плотности пикселей экрана).
5. **Динамический слой (интерактив 60 FPS):** лёгкая перерисовка светового блика, вспышек кристаллов и иризации поверх запечённого изображения при движении курсора или наклоне устройства.

### Критичное правило версионирования

* Всегда храните константу `ВЕРСИЯ_ГЕНОМА = 1`.
* Никогда не берите все случайные числа из одного общего потока генератора. Разделяйте потоки по строковым «солям» (`"v1:geo"`, `"v1:color"`, `"v1:mut"`, `"v1:geode"`).
* Если в будущем понадобится добавить новый признак или 9-ю мутацию, создание нового солёного потока гарантирует, что у всех старых пользователей их камни не изменятся ни на пиксель.

## 2. Детерминированное хэширование и PRNG

Стандартный системный генератор случайных чисел не поддерживает воспроизводимость по `seed`. Поскольку Unix timestamp в миллисекундах превышает 32 бита, его необходимо разделять на старшую и младшую 32-битные части перед смешиванием.

### 2.1. Получение seed с лавинным эффектом (на базе MurmurHash3 fmix32)

Сдвиг входного времени ровно на `1 мс` должен менять примерно 50% битов результата.

```text
ФУНКЦИЯ получить_seed(timestamp_мс, соль):
    младшие = остаток_от_деления(timestamp_мс, 2^32) в формате uint32
    старшие = целая_часть(timestamp_мс / 2^32) в формате uint32

    хэш = (младшие XOR умножить_uint32(старшие, 0x9E3779B1))

    ДЛЯ КАЖДОГО символа ИЗ соль:
        код = числовой_код_символа(символ)
        хэш = умножить_uint32(хэш XOR код, 0x85EBCA6B)

    // Финализатор лавинного эффекта (fmix32)
    хэш = хэш XOR битовый_сдвиг_вправо(хэш, 16)
    хэш = умножить_uint32(хэш, 0x85EBCA6B)
    хэш = хэш XOR битовый_сдвиг_вправо(хэш, 13)
    хэш = умножить_uint32(хэш, 0xC2B2AE35)
    хэш = хэш XOR битовый_сдвиг_вправо(хэш, 16)

    ВЕРНУТЬ хэш (как беззнаковое 32-битное целое)
```

### 2.2. Генератор псевдослучайных чисел (Mulberry32)

Возвращает равномерно распределённое дробное число в диапазоне `[0.0, 1.0)`.

```text
СТРУКТУРА Генератор:
    состояние: uint32

ФУНКЦИЯ создать_генератор(seed):
    ВЕРНУТЬ Генератор(состояние = seed)

ФУНКЦИЯ следующее_число(ген):
    ген.состояние = сложить_uint32(ген.состояние, 0x6D2B79F5)
    t = умножить_uint32(ген.состояние XOR сдвиг_вправо(ген.состояние, 15), 1 OR ген.состояние)
    t = t XOR сложить_uint32(t, умножить_uint32(t XOR сдвиг_вправо(t, 7), 61 OR t))
    результат = t XOR сдвиг_вправо(t, 14)
    ВЕРНУТЬ результат / 4294967296.0

ФУНКЦИЯ случайное_в_диапазоне(ген, мин, макс):
    ВЕРНУТЬ мин + следующее_число(ген) * (макс - мин)

ФУНКЦИЯ случайное_целое(ген, мин, макс):
    ВЕРНУТЬ округлить_вниз(случайное_в_диапазоне(ген, мин, макс + 1))
```

## 3. Спецификация генома

**Правило часовых поясов:** все календарные вычисления (час, минута, день года, фаза Луны) выполняются строго в **UTC**. Это гарантирует, что один и тот же профиль выглядит одинаково у пользователей в любой точке мира.

### 3.1. Макро-гены (читаемое время)

| Параметр | Источник | Логика расчёта | Визуальное влияние |
|---|---|---|---|
| `базовый_тон` (`base_hue`) | Час + минуты UTC (`0.0 .. 24.0`) | Кусочно-линейная интерполяция по суточному циклу | `00:00–04:59` — индиго/бирюза (`215°`); `05:00–09:59` — персик/розовый кварц (`25°`); `10:00–16:59` — сапфир/нефрит (`185°`); `17:00–21:59` — аметист/янтарь (`285°`); `22:00–23:59` — глубокий кобальт (`230°`) |
| `фактор_сезона` | День года UTC (`0 .. 365`) | `cos(2 * ПИ * день_года / 365)` -> диапазон `[-1, 1]` | `+1` (зима): резкие границы колец, холодная корка; `-1` (лето): мягкие переливы, тёплое ядро |
| `зрелость` (`age_factor`) | `текущее_время_мс - created_at_ms` | `минимум(1.0, log2(1 + дней_возраста) / 9.0)` | `0.0` (1-й день): базовые 45% колец, матовая поверхность; `1.0` (~511 дней): 100% колец, глубокий полированный блеск и чёткая друза |
| `фаза_луны` | `created_at_ms` | Смещение от опорного новолуния (`2000-01-06 18:14 UTC`) по модулю синодического периода `29.530588853` дней | `0.5 ± 0.03` соответствует полнолунию (используется для паспорта или редкой календарной метки) |

### 3.2. Микро-гены (из солёных потоков PRNG)

| Ген | Поток | Диапазон | Назначение |
|---|---|---|---|
| `число_гармоник` | `v1:geo` | Целое `4 .. 7` | Сложность внешнего силуэта камня |
| `шероховатость` | `v1:geo` | `0.12 .. 0.28` | Степень волнистости и асимметрии контура |
| `сжатие_оси_X` | `v1:geo` | `0.82 .. 1.18` | Вытянутость среза (горизонтальный или вертикальный овал) |
| `угол_поворота` | `v1:geo` | `0 .. 2*ПИ` | Начальный поворот всего камня |
| `базовое_число_колец` | `v1:geo` | Целое `12 .. 26` | Потенциальное число слоёв (раскрывается по мере роста `зрелости`) |
| `радиус_полости` | `v1:geo` | `0.16 .. 0.34` | Размер центральной кристаллической жеоды относительно радиуса |
| `смещение_полости` | `v1:geo` | `(-0.12 .. +0.12)` по `X, Y` | Смещение центра роста кристаллов от центра камня |
| `разброс_тона` | `v1:color` | `18° .. 65°` | Сдвиг оттенка между соседними минеральными кольцами |
| `контраст_слоёв` | `v1:color` | `0.35 .. 0.85` | Перепад светлоты между тёмными и молочными слоями |

### 3.3. Система мутаций (8 разновидностей)

Каждая мутация проверяется **отдельным независимым броском** из потока `v1:mut`. Благодаря этому возможны редчайшие двойные и тройные комбинации (например, `albino + kintsugi` с шансом `0.05%`).

| ID мутации | Шанс | Описание | Конфликты (исключения) |
|---|---|---|---|
| `kintsugi` | `5.0%` | Золотые или серебряные жилы-трещины от края к центру | Нет (совместима со всеми) |
| `double_geode` | `3.0%` | Две сросшиеся кристаллические полости внутри одного камня | Исключает `eye_agate` |
| `moss_dendrites` | `3.0%` | Ветвистые фрактальные включения («мох») в средних слоях | Нет (слабо заметна поверх `obsidian`) |
| `iridescence` | `2.0%` | Опаловый/бензиновый радужный перелив при движении света | Исключает `albino` |
| `eye_agate` | `2.0%` | Идеально круглое высококонтрастное «око» с радиальными лучами | Исключает `double_geode` |
| `albino` | `1.0%` | Лунный кварц: полное обесцвечивание, молочно-белая палитра | Исключает `obsidian`, `iridescence` |
| `obsidian` | `1.0%` | Почти чёрная вулканическая порода + 1 раскалённая светящаяся жила | Исключает `albino` |
| `inclusion` | `0.5%` | Застывший микро-артефакт внутри полупрозрачного слоя («инклюз») | Нет (совместима со всеми) |

```text
ФУНКЦИЯ вычислить_мутации(created_at_ms, календарные_правила_включены):
    ген = создать_генератор(получить_seed(created_at_ms, "v1:mut"))
    мутации = пустой_список()

    // Каждый вызов следующее_число выполняется всегда (даже при конфликте),
    // чтобы не сдвигать поток генератора для последующих мутаций.
    бросок_кинцуги   = следующее_число(ген)
    бросок_двойная   = следующее_число(ген)
    бросок_мох       = следующее_число(ген)
    бросок_иризация  = следующее_число(ген)
    бросок_око       = следующее_число(ген)
    бросок_альбинос  = следующее_число(ген)
    бросок_обсидиан  = следующее_число(ген)
    бросок_инклюз    = следующее_число(ген)

    ЕСЛИ бросок_кинцуги < 0.05 ТО добавить(мутации, "kintsugi")
    ЕСЛИ бросок_двойная < 0.03 ТО добавить(мутации, "double_geode")
    ЕСЛИ бросок_мох < 0.03 ТО добавить(мутации, "moss_dendrites")
    ЕСЛИ бросок_око < 0.02 И НЕ содержит(мутации, "double_geode") ТО добавить(мутации, "eye_agate")
    ЕСЛИ бросок_альбинос < 0.01 ТО добавить(мутации, "albino")
    ЕСЛИ бросок_обсидиан < 0.01 И НЕ содержит(мутации, "albino") ТО добавить(мутации, "obsidian")
    ЕСЛИ бросок_иризация < 0.02 И НЕ содержит(мутации, "albino") ТО добавить(мутации, "iridescence")
    ЕСЛИ бросок_инклюз < 0.005 ТО добавить(мутации, "inclusion")

    // Опциональные гарантированные календарные аномалии
    ЕСЛИ календарные_правила_включены ТО:
        ЕСЛИ час_UTC(created_at_ms) == 0 И минута_UTC(created_at_ms) == 0 И НЕ содержит(мутации, "albino") ТО:
            добавить_если_нет(мутации, "obsidian")
        ЕСЛИ абсолютное(фаза_луны(created_at_ms) - 0.5) <= 0.015 И НЕ содержит(мутации, "obsidian") ТО:
            добавить_если_нет(мутации, "albino")

    ВЕРНУТЬ мутации
```

## 4. Математическая модель геометрии

Все расчёты ведутся в нормализованной системе координат с центром в `(0, 0)` и базовым радиусом `R0 = 1.0`, после чего масштабируются под размер холста.

### 4.1. Внешний контур (полярный ряд Фурье с защитой от самопересечений)

Контур дискретизируется на `M = 180` точек (для миниатюр-аватарок достаточно `M = 60`). Гармоники начинаются с `k = 2`, так как `k = 1` лишь сдвигает фигуру.

```text
ФУНКЦИЯ построить_внешний_контур(ген, число_точек_M, гармоники, сжатие_X, поворот):
    // 1. Проверка безопасности (защита от «выворачивания» контура)
    сумма_амплитуд = сумма(абсолютное(h.амплитуда) ДЛЯ h ИЗ гармоники)
    ЕСЛИ сумма_амплитуд > 0.30 ТО:
        коэффициент = 0.30 / сумма_амплитуд
        ДЛЯ КАЖДОЙ h ИЗ гармоники:
            h.амплитуда = h.амплитуда * коэффициент

    // 2. Расчёт точек замкнутого полигона
    точки = пустой_список()
    ДЛЯ i ОТ 0 ДО число_точек_M - 1:
        угол = (i / число_точек_M) * 2 * ПИ
        радиус = 1.0
        ДЛЯ КАЖДОЙ h ИЗ гармоники:
            радиус = радиус + h.амплитуда * cos(h.частота_k * угол + h.фаза)

        x = радиус * cos(угол) * сжатие_X
        y = радиус * sin(угол)
        // Поворот точки на общий угол камня
        x_пов = x * cos(поворот) - y * sin(поворот)
        y_пов = x * sin(поворот) + y * cos(поворот)

        добавить(точки, Точка(x_пов, y_пов))

    ВЕРНУТЬ точки
```

### 4.2. Концентрические кольца без самопересечений

Чтобы внутренние слои минерала естественно повторяли форму внешней полости, плавно сглаживались к центру и **никогда не пересекали друг друга**, каждый слой строится через монотонную интерполяцию между внешним контуром `P_внеш` и гладким внутренним контуром жеоды `P_внутр`.

```text
ФУНКЦИЯ построить_кольца(P_внеш, P_внутр, видимое_число_колец, ген):
    // Генерируем случайные относительные толщины слоёв (тонкие нити + широкие полосы)
    веса = пустой_список()
    сумма_весов = 0.0
    ДЛЯ i ОТ 0 ДО видимое_число_колец - 1:
        // Квадрат случайного числа даёт красивый разброс от очень тонких до широких полос
        толщина = 0.15 + (следующее_число(ген) ^ 2) * 1.4
        добавить(веса, толщина)
        сумма_весов = сумма_весов + толщина

    кольца = пустой_список()
    накоплено = 0.0

    ДЛЯ i ОТ 0 ДО видимое_число_колец - 1:
        прогресс_w = накоплено / сумма_весов // строго возрастает от 0.0 до < 1.0
        контур_кольца = пустой_список()

        ДЛЯ j ОТ 0 ДО длина(P_внеш) - 1:
            x = (1.0 - прогресс_w) * P_внеш[j].x + прогресс_w * P_внутр[j].x
            y = (1.0 - прогресс_w) * P_внеш[j].y + прогресс_w * P_внутр[j].y
            добавить(контур_кольца, Точка(x, y))

        добавить(кольца, Кольцо(точки = контур_кольца, глубина = прогресс_w))
        накоплено = накоплено + веса[i]

    ВЕРНУТЬ кольца
```

### 4.3. Кристаллическая полость (Друза / Жеода)

Внутри контура `P_внутр` создаются полигональные грани кристаллов. Каждой грани заранее назначается 3D-вектор нормали для реалистичного блеска при движении света.

```text
ФУНКЦИЯ построить_кристаллы_жеоды(P_внутр, центр, радиус, ген):
    число_семян = случайное_целое(ген, 18, 34)
    семена = сгенерировать_равномерные_точки_внутри(P_внутр, число_семян, ген)
    // Построение диаграммы Вороного или триангуляции Делоне, обрезанной по P_внутр
    полигоны = построить_мозаику_внутри(семена, P_внутр)

    грани = пустой_список()
    ДЛЯ КАЖДОГО полигон ИЗ полигоны:
        // Случайный наклон грани кристалла в 3D пространстве
        nx = случайное_в_диапазоне(ген, -0.75, 0.75)
        ny = случайное_в_диапазоне(ген, -0.75, 0.75)
        nz = корень(максимум(0.1, 1.0 - nx*nx - ny*ny))
        нормаль = нормализовать_вектор(nx, ny, nz)

        базовая_яркость = случайное_в_диапазоне(ген, 0.55, 0.95)
        добавить(грани, Грань(полигон, нормаль, базовая_яркость))

    ВЕРНУТЬ грани
```

## 5. Послойный конвейер отрисовки (Статический буфер)

Отрисовка выполняется **методом художника** (снизу вверх) с использованием масок отсечения. Все замкнутые контуры рисуются сглаженными квадратичными кривыми через середины соседних отрезков, чтобы исключить видимую угловатость.

```text
ФУНКЦИЯ построить_гладкий_путь(холст, точки):
    N = длина(точки)
    начало = середина(точки[N - 1], точки[0])
    начать_путь(холст)
    переместить_перо(холст, начало.x, начало.y)

    ДЛЯ i ОТ 0 ДО N - 1:
        текущая = точки[i]
        следующая = точки[(i + 1) по модулю N]
        конец_дуги = середина(текущая, следующая)
        квадратичная_кривая_Безье(холст, контрольная = текущая, конечная = конец_дуги)

    замкнуть_путь(холст)
```

### Порядок отрисовки слоёв в `статический_буфер`

1. **Слой 1 — Базальтовая корка и тень:**
   * Включить мягкую падающую тень под камнем.
   * Залить внешний контур `P_внеш` тёмной матовой породой (насыщенность `12–22%`, светлота `10–18%`, оттенок производный от `base_hue`).
   * Отключить тень. Провести внутреннюю неровную кромку корки шириной `3–5%` от радиуса (создаёт переход от сырой породы к полированному камню).

2. **Слой 2 — Минеральные кольца (Халцедон):**
   * Вычислить контур внутреннего края корки (`95%` от `P_внеш`), сохранить состояние холста и установить его как **маску отсечения**.
   * В цикле от `i = 0` (край) до `видимое_число_колец - 1` (центр):
     * Вычислить цвет слоя в пространстве HSL на основе `base_hue`, `разброса_тона`, `контраста_слоёв` и активных цветовых мутаций (`albino` или `obsidian`).
     * Чередовать типы колец:
       * *Пигментное кольцо:* залить радиальным градиентом и обвести тонкой полупрозрачной границей кристаллизации (`альфа = 0.15..0.35`).
       * *Молочно-стеклянное кольцо:* светлая полупрозрачная заливка (`альфа = 0.25..0.55`), создающая ощущение оптической глубины.
   * Наложить поверх всех колец предварительно сгенерированный тайл мелкого монохромного минерального шума в режиме наложения `overlay` с прозрачностью `0.06`.

3. **Слой 3 — Центральная жеода:**
   * Построить зубчатую кромку «сахарного кварца» вокруг `P_внутр` (добавить к радиусу `P_внутр` мелкую высокочастотную волну `k = 28..42` с амплитудой `1.5%`). Залить белым/светло-дымчатым цветом.
   * Установить `P_внутр` как маску отсечения и отрисовать все `грани` кристаллов с их `базовой_яркостью` и тонким светлым контуром стыков.

4. **Слой 4 — Статическая часть активных мутаций:**
   Выполняется по алгоритмам из раздела 5.1.

### 5.1. Алгоритмы отрисовки всех 8 мутаций

#### 1. `kintsugi` (Золотые трещины)
```text
ФУНКЦИЯ нарисовать_кинцуги(холст, P_внеш, центр, ген):
    число_лучей = случайное_целое(ген, 2, 4)
    ДЛЯ луча ОТ 1 ДО число_лучей:
        точка = случайная_точка_из(P_внеш, ген)
        путь_трещины = [точка]
        пока расстояние(точка, центр) > 0.15:
            вектор_к_центру = нормализовать(центр - точка)
            случайный_поворот = случайное_в_диапазоне(ген, -0.55, 0.55) // радианы
            направление = повернуть_вектор(вектор_к_центру, случайный_поворот)
            шаг = случайное_в_диапазоне(ген, 0.04, 0.09)
            точка = точка + направление * шаг
            добавить(путь_трещины, точка)

        // Отрисовка в 3 прохода для эффекта объёмного металла в сколе
        обвести_ломаную(холст, путь_трещины, толщина = 3.2px, цвет = тёмная_тень_скола)
        обвести_ломаную(холст, путь_трещины, толщина = 2.0px, цвет = градиент_золота)
        обвести_ломаную(холст, сместить(путь_трещины, -0.5px, -0.5px), толщина = 0.7px, цвет = яркий_блик_золота)
```

#### 2. `double_geode` (Двойная жеода)
* Вместо одного центра генерируются два смещённых центра `C1` и `C2` на расстоянии `0.38..0.48` друг от друга.
* Внешний контур формируется как объединённая оболочка двух смещённых овалов (гладкий минимум расстояний / метабола).
* Первые `40%` внешних колец строятся общими (охватывают оба центра).
* Оставшиеся `60%` колец и сами кристаллические полости строятся **независимо** вокруг `C1` и вокруг `C2`.

#### 3. `moss_dendrites` (Моховые дендриты)
```text
ФУНКЦИЯ нарисовать_дендрит(холст, точка, угол, длина, глубина, ген):
    ЕСЛИ глубина == 0 ИЛИ длина < минимальный_порог ТО ВЕРНУТЬ

    конец = Точка(точка.x + cos(угол) * длина, точка.y + sin(угол) * длина)
    нарисовать_линию(холст, точка, конец, толщина = глубина * 0.45px, цвет = полупрозрачный_изумруд_или_охра)

    ветвей = случайное_целое(ген, 2, 3)
    ДЛЯ i ОТ 1 ДО ветвей:
        новый_угол = угол + случайное_в_диапазоне(ген, -0.65, 0.65)
        новая_длина = длина * случайное_в_диапазоне(ген, 0.55, 0.78)
        нарисовать_дендрит(холст, конец, новый_угол, новая_длина, глубина - 1, ген)

// Вызывается в режиме наложения "multiply" внутри маски средних слоёв (глубина кольца 0.25 .. 0.70)
// из 4–8 стартовых точек по периметру.
```

#### 4. `eye_agate` (Глазковый агат)
* Внутренний контур `P_внутр` принудительно превращается в идеальную окружность (амплитуды гармоник обнуляются).
* Для внутренних `35%` колец `контраст_слоёв` повышается до `0.95` (резкое чередование тёмного «зрачка» и светлой «радужки»).
* Из центра полости рисуются `45..65` тонких радиальных лучей переменной длины с градиентным затуханием к краям.

#### 5. `albino` (Лунный кварц)
* Модифицирует функцию расчёта палитры всех колец и корки:
  * Насыщенность `S` жёстко ограничивается диапазоном `0% .. 8%`.
  * Светлота `L` поднимается в диапазон `68% .. 97%`.
  * Усиливается контраст граней центральной жеоды и серебристая кромка сахарного кварца.

#### 6. `obsidian` (Обсидиановое затмение)
* Модифицирует палитру всех колец: светлота `L` опускается в диапазон `4% .. 16%`, насыщенность `S` — в `5% .. 20%`.
* Выбирается одно акцентное кольцо на глубине `w ≈ 0.65` — его контур обводится высококонтрастным неоновым/лавовым цветом с эффектом свечения (`blur`) в режиме наложения `lighter`.

#### 7. `inclusion` (Застывшее включение / инклюз)
* Рисуется **в середине цикла колец** (примерно после 65% слоёв), чтобы оставшиеся полупрозрачные слои легли поверх и создали эффект объекта под стеклом.
* В случайной точке среднего пояса размещается микро-артефакт (выбирается по гену): воздушный пузырёк с внутренним бликом, золотой октаэдр или миниатюрная геометрическая руна.
* Сохраняется координата инклюза для микро-параллакса в динамическом слое.

#### 8. `iridescence` (Огненный агат / Иризация)
* В статический буфер не запекается — полностью рассчитывается на динамическом слое (см. раздел 6), чтобы радужный перелив живо реагировал на угол падения света.

## 6. Динамический слой и оптимизация (60 FPS)

Перерисовывать все 25 колец, кривые Безье и фракталы каждый кадр недопустимо — это перегрузит мобильные GPU/CPU. Используется **двухбуферная схема**.

### 6.1. Ограничение разрешения (HiDPI)
* Коэффициент плотности пикселей ограничивается сверху: `dpr = минимум(системный_DPR, 2.0)`.
* Размер буфера: `ширина_буфера = ширина_элемента * dpr`, `высота_буфера = высота_элемента * dpr`.

### 6.2. Цикл анимации света (выполняется только при движении курсора/инерции)

```text
ФУНКЦИЯ отрисовать_кадр_динамики(видимый_холст, статический_буфер, геометрия, свет, мутации):
    // 1. Плавное сглаживание положения источника света (инерция)
    свет.x = свет.x + (свет.цель_x - свет.x) * 0.12
    свет.y = свет.y + (свет.цель_y - свет.y) * 0.12
    вектор_света = нормализовать_вектор(свет.x, свет.y, 0.85)

    // 2. Быстрое копирование запечённого камня (одна GPU-операция)
    очистить(видимый_холст)
    скопировать_изображение(из = статический_буфер, в = видимый_холст)

    // 3. Ограничение маской внешнего контура камня
    сохранить_состояние(видимый_холст)
    построить_гладкий_путь(видимый_холст, геометрия.P_внеш)
    установить_маску_отсечения(видимый_холст)

    // 4. Полированный блик на поверхности среза
    интенсивность_глянца = 0.10 + 0.16 * геометрия.зрелость
    точка_блика = центр_холста + (свет.x * радиус * 0.45, свет.y * радиус * 0.45)
    нарисовать_радиальный_градиент(
        холст = видимый_холст,
        центр = точка_блика,
        режим = "screen",
        от_цвета = белый(альфа = интенсивность_глянца),
        до_цвета = белый(альфа = 0.0)
    )

    // 5. Иризация (если активна мутация iridescence)
    ЕСЛИ содержит(мутации, "iridescence") ТО:
        угол_света = atan2(свет.y, свет.x)
        нарисовать_конический_радужный_градиент(
            холст = видимый_холст,
            начальный_угол = угол_света,
            маска = средние_кольца,
            режим = "color-dodge",
            прозрачность = 0.24
        )

    // 6. Реалистичное мерцание граней кристаллов в жеоде (модель Блинна-Фонга)
    ДЛЯ КАЖДОЙ грань ИЗ геометрия.грани_кристаллов:
        скаляр = максимум(0.0, скалярное_произведение(грань.нормаль, вектор_света))
        вспышка = скаляр ^ 6 // резкий пик блеска только под «правильным» углом

        ЕСЛИ вспышка > 0.08 ТО:
            залить_полигон(
                холст = видимый_холст,
                полигон = грань.полигон,
                режим = "lighter",
                цвет = белый(альфа = вспышка * 0.65)
            )

    восстановить_состояние(видимый_холст)

    // 7. Энергосбережение: остановить цикл анимации, когда свет догнал цель
    ЕСЛИ расстояние(свет.текущий, свет.цель) > 0.001 ТО:
        запланировать_следующий_кадр(отрисовать_кадр_динамики)
```

## 7. Жизненный цикл и интерфейс клиентского модуля

Рекомендуемый публичный API модуля `ГенераторАгата` для интеграции в любой UI-фреймворк:

```text
КЛАСС ГенераторАгата:
    ПОЛЯ:
        видимый_холст
        статический_буфер
        created_at_ms
        геном
        геометрия
        состояние_света
        режим_упрощённого_движения

    КОНСТРУКТОР(элемент_холста, created_at_ms, опции):
        проверить_валидность(created_at_ms)
        текущее_время = опции.now ИЛИ системное_время_UTC_мс()
        режим_упрощённого_движения = проверить_настройку_ОС("prefers-reduced-motion")

        геном = собрать_геном(created_at_ms, текущее_время)
        геометрия = построить_геометрию(геном, детализация = опции.детализация)

        настроить_размер_с_учётом_DPR()
        запечь_статический_слой()
        отрисовать_кадр_динамики()

        ЕСЛИ НЕ режим_упрощённого_движения И НЕ опции.только_статика ТО:
            подписаться_на_движение_курсора_и_касания()

    МЕТОД получить_паспорт_генома():
        // Возвращает структурированные данные для UI-карточки профиля:
        // версия, время суток, зрелость в %, список мутаций, итоговый индекс редкости
        ВЕРНУТЬ сформировать_паспорт(геном)

    МЕТОД вычислить_индекс_редкости():
        // Перемножение базовых вероятностей всех выпавших мутаций
        вероятность = 1.0
        ДЛЯ КАЖДОЙ мутация ИЗ геном.мутации:
            вероятность = вероятность * таблица_шансов[мутация]
        ВЕРНУТЬ вероятность // например, 0.0005 означает "1 из 2000"

    МЕТОД экспортировать_как_изображение(формат):
        // Используется для кэширования аватарок или кнопки "Скачать артефакт"
        ВЕРНУТЬ кодировать_буфер(статический_буфер, формат)

    МЕТОД уничтожить():
        отменить_запланированный_кадр()
        отписаться_от_событий_курсора()
        освободить_память_буфера()
```
