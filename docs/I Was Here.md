
# Описание предметной области
I Was Here -  программный продукт, который отображает пользователей, которые зарегестрированы в нем. Пользователь может зарегестрироваться указав логин и пароль, удалить свою учетную запись, 




# 📦Сущности
## Пользователь
- логин
- пароль




# 📃Требования
## Пользователь
1) может ввести логин при регистрации.
2) может ввести пароль при регистрации.
3) может зарегестрироваться.
4) может изменить свой логин
5) может изменить свой пароль
6) может удалить свою учетную запись.





# ⛔Ограничения
## Пользователь
1) длина логина должна быть от 3 до 32 символов
2) длина пароля должна быть от 8 до 64 символов
3) логин должен быть уникальным

# 📄REST-API

| №   | Функциональность                     | Метод  | URL                                   |
| --- | ------------------------------------ | ------ | ------------------------------------- |
| 1   | Создать пользователя                 | POST   | /users                                |
| 2   | Получить список пользователей        | GET    | /users/?limit={limit}&cursor={cursor} |
| 3   | Получить конкретного пользователя    | GET    | /users/{id}                           |
| 4   | Изменить учетные данные пользователя | PATCH  | /users/{id}                           |
| 5   | Удалить пользователя                 | DELETE | /users/{id}                           |
